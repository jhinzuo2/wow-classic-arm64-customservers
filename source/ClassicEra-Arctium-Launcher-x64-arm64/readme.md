# Arctium Style Launcher for Classic Era

A custom launcher designed for World of Warcraft Classic Era, tailored for target build `1.14.2.42597`, optimized for **ARM64** platforms, and fully compatible with **Wine**.

---

## Supported Versions & Platforms

| Version | Architecture / Environment | Status | Notes |
| :--- | :--- | :--- | :--- |
| **1.14.2.42597** | ARM64 / Wine / x64 | Fully Supported | Initial target build |
| *More versions* | — | Planned | Future updates pending |

---

## Features
* Arctium-style launcher framework adapted for Classic Era.
* Native execution capabilities on ARM64 environments and full **Wine** compatibility for cross-platform setups.
* Target build validation for `1.14.2.42597`.
* Optimized for custom authentication and proxy redirection.

---

## Getting Started

1. Place the launcher files into your World of Warcraft Classic Era directory containing build `1.14.2.42597`.
2. Configure your connection settings and custom authkeys as required by your private server setup.
3. Run the application (via Wine on Linux/ARM environments or natively where supported).
