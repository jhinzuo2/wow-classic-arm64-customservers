# ClassicForeverLauncher

A custom launcher utility designed for Classic World of Warcraft private server environments, optimized for **ARM64** platforms, and fully compatible with **Wine**.

---

## Supported Versions & Platforms

| Version | Architecture / Environment | Status | Notes |
| :--- | :--- | :--- | :--- |
| **1.60.1.70009** | ARM64 / Wine / x64 | Fully Supported | Initial release / primary target build |
| *More versions* | — | Planned | Coming in future updates |

---

## Features
* Custom build loading for target Classic client versions.
* Native execution support on **ARM64** and seamless compatibility with **Wine** for Linux/cross-platform setups.
* Designed to interface seamlessly with private server proxies and custom authkey configurations.
* Lightweight and streamlined execution.

---

## Getting Started

1. Download or clone the repository.
2. Place the launcher files into your target World of Warcraft directory containing the supported client version (`v1.60.1.70009`).
3. Configure your connection settings/authkeys as required by your target private server.
4. Run the executable (via Wine on Linux/ARM environments or natively where supported).
